# Panduan Pengumpulan AOL

### Deadline

Pengumpulan paling lambat pada **11 Juni pukul 23.59 WIB**.

### Pengumpulan di

Dikumpulkan di **BINUS MAYA** → Session 26 → Assessment AOL - Project

### Format Pengumpulan

Dapat berupa:
- ZIP file yang berisi semua file yang harus dikumpulkan, atau
- Link ke folder Google Drive yang berisi semua file

---

### Apa Saja yang Harus Dikumpulkan?

1. **Software**
   - Link website / app
   - Link repository GitHub

2. **Dokumentasi Software**
   - File `README.md` di GitHub, atau
   - Dokumen tersendiri (Notion, PDF, dll.)

3. **Demo Video**
   - Video yang mendemonstrasikan fitur-fitur software

4. **Laporan PKM-KC**
   - Laporan tertulis berformat PKM-KC

5. **Presentasi**
   - File PPT / Canva
   - Presentasi project di depan kelas
